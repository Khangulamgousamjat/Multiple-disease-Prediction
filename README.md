# Multiple Disease Prediction Web Application

An intelligent, interactive Machine Learning web application built with **Streamlit** and **Python** to predict multiple diseases accurately based on user symptoms, clinical parameters, and medical history.

---

## 🌟 Key Features

* **General Disease Prediction**: Predict common conditions from multi-symptom inputs.
* **Diabetes Prediction**: Predict diabetes risk using diagnostic measurements.
* **Heart Disease Prediction**: Assess cardiovascular risk factors.
* **Parkinson's Disease Prediction**: Voice measure and biomedical analysis.
* **Liver Disease Prediction**: Evaluate liver function test indicators.
* **Hepatitis Prediction**: Early detection using clinical biomarkers.
* **Lung Cancer Prediction**: Risk evaluation based on lifestyle and symptom indicators.
* **Chronic Kidney Disease Prediction**: Renal health risk assessment.
* **Breast Cancer Prediction**: Diagnostic classification based on tumor features.

---

## 🚀 Quick Start (Local Setup)

### 1. Clone the repository
```bash
git clone https://github.com/Khangulamgousamjat/Multiple-disease-Prediction.git
cd Multiple-disease-Prediction
```

### 2. Install dependencies
```bash
pip install -r requirements.txt
```

### 3. Run the application
```bash
streamlit run app.py
```

---

## ☁️ Deployment (Streamlit Community Cloud)

1. Fork or push this repository to GitHub.
2. Go to [share.streamlit.io](https://share.streamlit.io/) and log in with GitHub.
3. Select this repository: `Khangulamgousamjat/Multiple-disease-Prediction`
4. Set **Branch**: `main` and **Main file path**: `app.py`
5. Click **Deploy!**
